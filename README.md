# MonsterMashup
Monster Rythm Mash Game

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## 📖 About The Project
This repository contains the Unreal Engine 5 game project **Batoven**.
Key features include note charts synced to music with FMOD timeline markers, timing-based accuracy, combos and end-of-song ranks, tap and hold notes across two lanes, animated Paper2D enemies, menus and a looping song select. This project aims to deliver a tactile and engaging rhythm experience.

---
## 📖 Getting Started
Follow these instructions to get a copy of the project up and running on your local machine for development and testing.

### Prerequisites
* **Epic Games Launcher** installed.
* **Unreal Engine 5.4.4** You can install it via the Epic Games Launcher.
* **Git** (for cloning the repository).

### Installation
1. **Clone the repository:**
```sh
git clone
[https://github.com/DeclanTanner/MonsterMashup.git]
```
(Alternatively, for private collaboration: or contact `dttanner76@gmail.com` to be added as
a contributor.)

2. **Open the project in the Epic Games Launcher:**
* Launch Unreal Engine 5.4.4.
* Click "Open" or "Add project from disk".
* Navigate to the cloned `MonsterMashup` folder and select it.

3. **Open the project in the Unreal Engine 5.4.4 Editor:**
* Once added, click on the project name in UE5.4.4 to open it in the Unreal
Editor.
* Unreal will import assets and compile scripts. This might take a few minutes
the first time.

4. **Open the main scene:**
* Once the editor is open, locate the main scene file
* (`Content/Mash/Levels/MainMenu.umap`) in the Content Browser and double-click it to open.
